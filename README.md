# 🎧 Spoti5 – Mobile Music Streaming App

Spoti5 là ứng dụng nghe nhạc trên mobile lấy cảm hứng từ Spotify, cho phép người dùng khám phá, phát nhạc và quản lý playlist cá nhân với trải nghiệm hiện đại và mượt mà.

---

## Features

- Tìm kiếm bài hát, nghệ sĩ và album
- Phát nhạc trực tuyến
- Thêm bài hát vào danh sách yêu thích
- Tạo và quản lý playlist cá nhân
- Đăng ký / Đăng nhập tài khoản
- Giao diện UI/UX hiện đại giống các app streaming phổ biến
- Tối ưu trải nghiệm mobile (dark mode/light mode)
